# Unique WellCare Appointment Form Setup

The website submits appointment requests to the Vercel API route at `/api/appointment`.
That route validates the form server-side and forwards accepted requests to a Google Apps Script web app, which writes to Google Sheets, stores the optional prescription file in Google Drive, and emails `ubercare@uber-india.com`.

## Google Apps Script

1. Sign in as `rauf.shaikh.capdbi@gmail.com`, or the Google account that should own/manage the appointment Sheet.
2. Create a new Apps Script project.
3. Paste the contents of `google-apps-script/appointment-handler.gs` into `Code.gs`.
4. In Project Settings, add these Script Properties:
   - `UNIQUE_WELLCARE_SHARED_SECRET`: a long random secret. Use the same value in Vercel.
   - `UNIQUE_WELLCARE_SHEET_ID`: optional. Set this to an existing Google Sheet ID, or omit it and the script will create `Unique WellCare Appointment Requests` on first successful submission.
   - `UNIQUE_WELLCARE_DRIVE_FOLDER_ID`: optional. Set this to the Drive folder ID where uploaded prescriptions should be saved. If omitted, files are saved to the script owner's Drive root.
5. Deploy the script as a Web App:
   - Execute as: `Me`
   - Who has access: `Anyone`
6. Copy the Web App URL.

## Vercel Environment Variables

Add these to the Vercel project:

- `UNIQUE_WELLCARE_APPS_SCRIPT_URL`: the deployed Apps Script Web App URL.
- `UNIQUE_WELLCARE_SHARED_SECRET`: the same long random secret configured in Apps Script.

Redeploy the site after adding the variables.

## Form Fields

The current appointment form submits:

- Patient Name
- Patient Mobile Number
- Location
- Doctor Prescription file, optional
- Prescription uploads are limited to 3 MB and accept images or PDF files.
- Submission ID, generated by the browser for duplicate protection

Successful submissions redirect to `/thank-you/`.
